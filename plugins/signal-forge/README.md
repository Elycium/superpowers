# signal-forge

Three skills that work as one chain, plus `/forge` to run all three in one command:

```
Sources A, B, C
   │
   ▼
① high-signal-data-architect   → cited cards (@FragA:P2 …)
   │
   ▼
② get-more-perspectives         → panel votes + RECONSTRUCTION DIRECTIVE
   │
   ▼
③ reverse-engineer              → unified pipeline + CONFLICTS + GAPS
```

- **Step 1: Extract.** Strips narrative and keeps only what changes behavior. Every item carries a source locus, and nothing is invented.
- **Step 2: Decide.** A 5-advisor panel reviews the cards and decides what to build around. Its rulings are labeled `DECISION @panel (vote)` so they're never mistaken for source facts.
- **Step 3: Rebuild.** Reconstructs the system along the panel's direction. Any conflict the panel didn't rule on is surfaced, not resolved.

**`/forge`** runs the full chain. It pauses once, only if the panel split or declined on something, and you decide those (labeled `DECISION @user`). Each skill also works on its own. The panel can be used for any generative-AI or invention decision.

Shared notation: `[S1: Action] @FragA:P2`, `->` sequence, `+` concurrency, `?` decision, `|` branch.
